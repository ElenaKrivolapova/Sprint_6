# Sprint_6

Автотесты для сервиса аренды самокатов Scooter.

## Реализованные тесты

### test_faq.py

Проверка блока «Вопросы о важном»:
- клик по каждому вопросу,
- проверка текста ответа.

### test_order.py

Проверка оформления заказа самоката:
- заказ через верхнюю кнопку «Заказать»,
- заказ через нижнюю кнопку «Заказать»,
- заполнение формы заказа,
- подтверждение заказа,
- проверка успешного оформления.

### test_logo.py

Проверка логотипов:
- переход на главную страницу Самоката при клике на логотип Самоката,
- открытие страницы Дзена в новой вкладке при клике на логотип Яндекса.
